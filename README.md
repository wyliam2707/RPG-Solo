# RPG Solo — Índice Canônico

Este repositório é a memória persistente da campanha longa de **Wyliam D. Costa**.

A prioridade não é guardar tudo no mesmo arquivo, e sim manter cada tipo de informação no lugar certo para evitar contradições, duplicação e resumos cada vez maiores.

## Ordem de leitura para retomar a campanha

1. `livro/estado-atual.md` — ponto exato de retomada e condições ativas.
2. `referencia/guia-operacional.md` — regras de interpretação de Wyliam, Wanda, Ravena e do trio.
3. `referencia/fios-abertos.md` — mistérios, promessas e problemas ainda não encerrados.
4. `referencia/npcs-recursos.md` — NPCs, aliados, coleção, itens e recursos relevantes.
5. `livro/indice.md` — mapa dos capítulos e onde procurar fatos antigos.
6. Consultar o último capítulo completo quando a cena exigir detalhes finos.
7. Consultar os documentos profundos abaixo apenas quando o tema específico surgir.

## Referências profundas

- `personagem.md` — história, natureza, Paradoxos, cicatrizes, capacidades e traços permanentes de Wyliam.
- `dinamica-trio.md` — relação e funcionamento de Wyliam, Wanda e Ravena.
- `poderes.md` — magia velada, aberta, vulgar, barreiras e Alerta de Limiar Vulgar.
- `cenario.md` — Terra-27, tom de crossover, sociedade e referências de Wanda/Ravena.
- `estilo-narrativo.md` — agência do jogador, ritmo, voz, romance e forma da narração.

## Livro

A pasta `livro/` guarda a história já jogada.

- Os capítulos concluídos são **registro histórico**, não devem ser reescritos para acomodar decisões posteriores.
- `estado-atual.md` deve permanecer curto e conter somente o que é necessário para continuar agora.
- Fatos permanentes descobertos em capítulos devem migrar para os arquivos de referência apropriados.
- Fios ainda abertos devem migrar para `referencia/fios-abertos.md`.

## Regra de precedência

Quando dois arquivos parecerem divergir, usar esta ordem:

1. fato explicitamente estabelecido no jogo mais recente;
2. `livro/estado-atual.md`;
3. `referencia/guia-operacional.md`;
4. arquivo profundo específico (`dinamica-trio.md`, `personagem.md`, `poderes.md`, `cenario.md`, `estilo-narrativo.md`);
5. capítulo onde o fato ocorreu;
6. documentos arquivados/históricos.

Documentos antigos podem refletir uma fase anterior da campanha. Eles não anulam evolução posterior.

## Regra de manutenção para campanha longa

Ao encerrar cada capítulo:

- salvar o capítulo completo;
- atualizar `livro/estado-atual.md` apenas com a situação presente e o ponto de retomada;
- atualizar `referencia/fios-abertos.md` quando um mistério nasce, muda ou é encerrado;
- atualizar `referencia/npcs-recursos.md` quando NPCs, itens ou recursos mudam de estado;
- atualizar `referencia/guia-operacional.md` ou arquivos profundos somente quando surgir uma regra permanente de personagem, relação, magia ou estilo.

Evitar repetir a história inteira em todos os arquivos. Para fatos antigos, usar o índice e o capítulo correspondente.
